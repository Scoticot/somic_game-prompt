# somic_game-prompt# 
Sonic: Systemic Game Design Analysis

## Описание проекта

Проект посвящён системной деконструкции классической 2D-серии Sonic the Hedgehog и исследованию её игровых механик.

## Цель проекта

Изучить основные игровые системы Sonic, определить принципы взаимодействия игрока с игровым миром и разработать экспериментальные изменения правил игры.

## Структура проекта

1. Долгосрочная цель и игровые средства.
2. Основной игровой цикл (Core Loop).
3. Матрица игровых ресурсов.
4. Механика значимого выбора (Trade-off).
5. Экспериментальные мутации игровых правил.

## Файлы проекта

- PROMPT.md — исходный запрос для анализа игры.
- ANALYSIS.md — результаты системной деконструкции.
- MUTATIONS.md — экспериментальные изменения игровых правил.

## Объект исследования

Sonic the Hedgehog — классический двухмерный платформер.
